# Propuesta de rediseño · Olimpo Spa

Borrador publicado con GitHub Pages para revisión del cliente.

- `index.html`: maqueta de la página de inicio (versión 3.0).
- `propuesta.html`: documento de la propuesta (diagnóstico, mapa del sitio, contenido, dirección visual, plan).

Las páginas tienen `noindex` y `robots.txt` para que los buscadores no las indexen. Precios, horario, formas de pago, especialidades y reseñas son marcadores por completar.
