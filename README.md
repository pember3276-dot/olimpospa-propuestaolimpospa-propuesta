# Propuesta de rediseño · Olimpo Spa

Borrador de la propuesta de rediseño de olimpospa.com.co, publicado con GitHub Pages para revisión del cliente.

La página tiene `noindex` y `robots.txt` para que los buscadores no la indexen mientras sea un borrador. Precios, horario, formas de pago, terapeutas y reseñas son marcadores por completar.
